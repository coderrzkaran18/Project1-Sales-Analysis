# Sales Analysis Dashboard | Power BI

## Project Overview

This project is an interactive Sales Analysis Dashboard built using Power BI.

The dashboard analyzes sales performance using customer, product, promotion, and fact-sales data. It helps users understand sales trends, customer behavior, product performance, and the impact of promotions.

## Tools and Technologies

- Power BI Desktop
- Power BI Project format (PBIP)
- DAX
- Data Modeling
- Git and GitHub

## Data Model

The Power BI semantic model includes the following tables:

- `Fact Table` – sales transaction data
- `Dim Customers` – customer-related information
- `Dim Product` – product-related information
- `Dim Promotion` – promotion-related information
- Date tables – used for time-based analysis

## Key Dashboard Features

- Sales performance analysis
- Product-wise analysis
- Customer-wise analysis
- Promotion analysis
- Date-based sales trends
- Interactive filters and visualizations
